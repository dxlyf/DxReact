## 1️⃣ 初始化 & 配置

| 命令 | 说明 |
| :--- | :--- |
| `git init` | 在当前目录初始化一个新的 Git 仓库 |
| `git clone <url>` | 克隆远程仓库到本地 |
| `git config --global user.name "name"` | 设置全局用户名 |
| `git config --global user.email "email"` | 设置全局邮箱 |
| `git config --list` | 查看当前所有配置 |
| `git config --global core.editor "code --wait"` | 设置默认编辑器（示例：VS Code） |

---

## 2️⃣ 基本快照操作（日常提交）

| 命令 | 说明 |
| :--- | :--- |
| `git status` | 查看当前工作区和暂存区的状态（最常用） |
| `git add <file>` | 将指定文件添加到暂存区 |
| `git add .` | 添加当前目录下所有修改/新增的文件 |
| `git add -A` | 添加所有修改/新增/删除的文件（等价于 `git add .` 但更彻底） |
| `git commit -m "message"` | 提交暂存区内容，并附上提交信息 |
| `git commit -a -m "message"` | 跳过 `git add`，直接提交所有已跟踪文件的修改（不包括新文件） |
| `git commit --amend -m "new message"` | 修改最近一次提交的信息或内容 |
| `git rm <file>` | 从工作区和暂存区删除文件 |
| `git mv <old> <new>` | 移动或重命名文件（Git 会自动跟踪） |

---

## 3️⃣ 查看历史 & 差异

| 命令 | 说明 |
| :--- | :--- |
| `git log` | 查看提交历史 |
| `git log --oneline` | 单行简洁模式查看历史（最常用） |
| `git log --graph --oneline --decorate` | 图形化查看分支历史 |
| `git log -p <file>` | 查看某个文件的详细修改历史 |
| `git diff` | 查看工作区与暂存区的差异 |
| `git diff --staged` | 查看暂存区与上次提交的差异 |
| `git diff <commit1> <commit2>` | 比较两次提交之间的差异 |
| `git blame <file>` | 查看文件中每一行最后是谁修改的（定位问题用） |
| `git show <commit>` | 查看某次提交的详细信息 |

## 4️⃣ 分支管理

| 命令 | 说明 |
| :--- | :--- |
| `git branch` | 列出本地分支（当前分支前有 `*` 标记） |
| `git branch -r` | 列出远程分支 |
| `git branch -a` | 列出所有分支（本地 + 远程） |
| `git branch <branch-name>` | 创建新分支 |
| `git branch -d <branch-name>` | 删除本地分支（安全删除） |
| `git branch -D <branch-name>` | 强制删除未合并的分支 |
| `git checkout <branch-name>` | 切换分支 |
| `git checkout -b <branch-name>` | 创建并切换到新分支 |
| `git switch <branch-name>` | 切换分支（Git 2.23+ 推荐，语义更清晰） |
| `git switch -c <branch-name>` | 创建并切换（Git 2.23+） |
| `git merge <branch>` | 将指定分支合并到当前分支 |
| `git merge --abort` | 合并冲突后，放弃本次合并 |
| `git rebase <branch>` | 将当前分支变基到目标分支（线性历史） |
| `git rebase --continue` | 解决冲突后继续变基 |
| `git rebase --abort` | 放弃变基操作 |

## 5️⃣ 远程仓库同步

| 命令 | 说明 |
| :--- | :--- |
| `git remote -v` | 查看远程仓库地址 |
| `git remote add origin <url>` | 添加远程仓库（一般叫 origin） |
| `git remote remove origin` | 移除远程仓库 |
| `git push origin <branch>` | 将本地分支推送到远程 |
| `git push -u origin <branch>` | 推送并建立上游跟踪（以后可以直接 `git push`） |
| `git push origin --delete <branch>` | 删除远程分支 |
| `git push --tags` | 推送所有标签到远程 |
| `git pull` | 拉取远程当前分支的更新并合并（等价于 `fetch + merge`） |
| `git pull --rebase` | 拉取并用变基方式合并（推荐，避免多余的 merge 节点） |
| `git fetch` | 只拉取远程更新，不自动合并 |
| `git fetch --prune` | 拉取的同时清理远程已删除分支的本地跟踪 |

## 6️⃣ 撤销 & 重置

| 命令 | 说明 |
| :--- | :--- |
| `git restore <file>` | 丢弃工作区的修改（恢复成暂存区或最后一次提交的状态） |
| `git restore --staged <file>` | 将文件从暂存区撤出（等于 `git reset HEAD <file>`） |
| `git reset HEAD <file>` | 同上（旧语法） |
| `git reset --soft <commit>` | 撤销提交，但保留修改在暂存区 |
| `git reset --mixed <commit>` | 撤销提交和暂存，但保留修改在工作区（默认行为） |
| `git reset --hard <commit>` | 彻底回退到某个提交，丢弃所有后续修改（⚠️危险） |
| `git revert <commit>` | 通过创建一个新提交来“反向操作”某次提交（安全撤销） |
| `git clean -fd` | 删除未跟踪的文件和目录（⚠️不可恢复） |

## 7️⃣ 暂存 & 储藏

| 命令 | 说明 |
| :--- | :--- |
| `git stash` | 临时保存当前工作区的修改（用于切换分支） |
| `git stash save "message"` | 储藏并附带说明信息 |
| `git stash list` | 查看所有储藏记录 |
| `git stash pop` | 恢复最近一次储藏并从列表中删除 |
| `git stash apply` | 恢复最近一次储藏但保留在列表中 |
| `git stash drop` | 删除某个储藏 |
| `git stash clear` | 清空所有储藏（⚠️小心） |

---

### 一、查看与信息

| 命令 | 作用 |
|------|------|
| `git branch` | 列出本地分支，当前分支高亮 |
| `git branch -v` | 列出本地分支 + 最后一次提交信息 |
| `git branch -vv` | 列出本地分支 + 上游跟踪关系（远程分支） |
| `git branch -r` | 只显示远程分支 |
| `git branch -a` | 显示所有分支（本地 + 远程） |
| `git branch --merged` | 显示已合并到当前分支的分支列表 |
| `git branch --no-merged` | 显示尚未合并到当前分支的分支列表 |
| `git log --oneline --graph --branches` | 图形化查看所有分支历史 |
| `git show-branch` | 简洁展示各分支提交差异 |

---

### 二、创建与切换

| 命令 | 作用 |
|------|------|
| `git branch <branch_name>` | 基于当前 HEAD 创建新分支（不切换） |
| `git branch <new_branch> <commit_id>` | 基于指定 commit 创建分支 |
| `git branch <new_branch> <remote>/<branch>` | 基于远程分支创建本地分支 |
| `git checkout <branch_name>` | 切换到指定分支（旧语法） |
| `git switch <branch_name>` | 切换到指定分支（Git 2.23+，推荐） |
| `git checkout -b <branch_name>` | 创建并切换到新分支（旧语法） |
| `git switch -c <branch_name>` | 创建并切换到新分支（Git 2.23+，推荐） |
| `git checkout -b <new_branch> <base_branch>` | 基于指定分支创建并切换 |

---

### 三、删除与重命名

| 命令 | 作用 |
|------|------|
| `git branch -d <branch_name>` | 删除本地分支（安全模式，已合并才可删） |
| `git branch -D <branch_name>` | 强制删除本地分支（不检查是否合并） |
| `git push origin --delete <branch_name>` | 删除远程分支 |
| `git push origin :<branch_name>` | 同上，另一种写法（`:` 前缀表示删除） |
| `git branch -m <old_name> <new_name>` | 重命名当前分支 |
| `git branch -m <new_name>` | 重命名当前分支（省略旧名） |
| `git push origin -u <new_name>` | 重命名后重新推送并设置上游 |
| `git push origin --delete <old_name>` | 重命名后删除远程旧分支 |

---

### 四、合并与变基

| 命令 | 作用 |
|------|------|
| `git merge <branch_name>` | 将指定分支合并到当前分支（快进合并） |
| `git merge --no-ff <branch_name>` | 强制非快进合并（生成 merge commit） |
| `git merge --squash <branch_name>` | 压缩合并（所有提交合并为一个变更，不生成提交） |
| `git merge --abort` | 合并冲突时，放弃本次合并 |
| `git rebase <base_branch>` | 将当前分支的提交重放到目标分支之上 |
| `git rebase --continue` | 解决冲突后继续变基 |
| `git rebase --abort` | 放弃变基，恢复原状 |
| `git rebase -i HEAD~n` | 交互式变基，压缩/修改/排序提交 |

---

### 五、推送、拉取与跟踪

| 命令 | 作用 |
|------|------|
| `git push origin <branch_name>` | 推送本地分支到远程同名分支 |
| `git push -u origin <branch_name>` | 推送并设置上游跟踪关系（后续直接用 `git push`） |
| `git push --all origin` | 推送所有本地分支到远程 |
| `git fetch origin` | 下载远程所有分支更新（不合并） |
| `git fetch origin <branch>` | 只 fetch 指定远程分支 |
| `git fetch --prune` | fetch 并清理本地已删除的远程分支引用 |
| `git pull origin <branch_name>` | fetch + merge 到当前分支 |
| `git pull --rebase origin <branch_name>` | fetch + rebase 到当前分支 |
| `git branch --set-upstream-to=origin/<branch> <local_branch>` | 为本地分支设置/修改上游跟踪 |
| `git branch -u origin/<branch>` | 同上，简写 |

---

### 六、比较与差异

| 命令 | 作用 |
|------|------|
| `git diff <branch1> <branch2>` | 比较两个分支的差异 |
| `git diff <branch>` | 比较当前分支与指定分支的差异 |
| `git diff <branch1>..<branch2>` | 两点差异（从 branch1 到 branch2） |
| `git diff <branch1>...<branch2>` | 三点差异（共同祖先到 branch2） |
| `git log <branch1>..<branch2>` | 查看 branch2 有但 branch1 没有的提交 |
| `git log --left-right <branch1>...<branch2>` | 对比两个分支各自独有的提交 |

---

### 七、恢复与修复

| 命令 | 作用 |
|------|------|
| `git branch <new_branch> <old_branch>@{n}` | 基于 reflog 中某次历史状态创建分支（恢复误删分支） |
| `git reflog` | 查看 HEAD 的历史移动记录（找丢失的 commit） |
| `git checkout <commit_id>` | 切换到某次提交（detached HEAD 状态） |
| `git switch -c <branch> <commit_id>` | 从某次 commit 创建新分支并切换 |
| `git cherry-pick <commit_id>` | 将某个提交复制到当前分支 |
| `git reset --hard <commit_id>` | 强制将当前分支回退到某次提交（危险） |
| `git reset --soft <commit_id>` | 回退但保留工作区变更 |

---

### 八、清理与维护

| 命令 | 作用 |
|------|------|
| `git remote prune origin` | 清理本地保存的、但远程已删除的分支引用 |
| `git branch --merged | grep -v "main" \| xargs git branch -d` | 批量删除已合并到 main 的分支（Linux/Mac） |
| `git branch --merged | findstr /v "main" | xargs git branch -d` | 同上（Windows cmd） |
| `git gc` | 垃圾回收，压缩仓库（优化性能） |

---

### 速查口诀（核心命令）

> **查看**用 `branch`，**创建**加 `-b`，  
> **切换**用 `switch`，**删除**用 `-d`，  
> **合并**用 `merge`，**变基**用 `rebase`，  
> **推送**设 `-u`，**拉取**选 `--rebase`。
